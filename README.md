# ForgeFPV

**American FPV Tactical Drone Trainer** — SkyForge Dynamics

Train rate-mode FPV skills: fly, find targets, score hits.

## Play in 3 steps

1. Install [Godot 4.7.1](https://godotengine.org/download) (standard build, not .NET)
2. Download this repo (Code → Download ZIP) and extract
3. Open Godot → **Import** → select `project.godot` → press **F5**

### Controls
| Action | Key |
|--------|-----|
| Throttle up | Space |
| Throttle down | Ctrl |
| Pitch / Roll | W A S D |
| Yaw | Q / E |
| Back to menu | Esc |

### What works now
- Main menu → Donbas / Urban maps
- Rate-style FPV flight with battery drain
- Ground targets + score on proximity hit
- On-screen HUD (speed, altitude, battery, score)

### Not yet (roadmap toward UFDS-class)
- Full Newton-Euler motor model parity
- RC radio binding / rates UI
- Academy mission tree
- Multiplayer
- High-detail photogrammetry maps
