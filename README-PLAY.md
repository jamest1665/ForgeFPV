# ForgeFPV — Play Now (3 Steps)

**American FPV Tactical Drone Trainer**

### For Players (Standalone Build)

1. Go to [Releases](https://github.com/jamest1665/ForgeFPV/releases)
2. Download the ZIP for your system:
   - **Windows** → `ForgeFPV-Windows.zip`
   - **Linux** → `ForgeFPV-Linux.zip`
3. Extract the ZIP and double-click **ForgeFPV.exe** (Windows) or **ForgeFPV.x86_64** (Linux)

That’s it. No installers. No Godot required.
