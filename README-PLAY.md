# ForgeFPV — Quick Play

1. Install Godot 4.7.x (standard, not .NET)
2. Open `project.godot` in this folder
3. Press **F5**

**Fly:** WASD · Q/E · Space/Ctrl  
**Pause:** Esc · **Help:** H

Hit red targets to score. Use **Academy Missions** for structured drills.
